# FoundationCrackPro.com

Next.js 16 pSEO site generated from `Foundation Crack - pSEO.xlsx`.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm run build
npm run start
```

## Data source

- Spreadsheet import output: `data/foundation-pages.generated.json`
- Total generated pages: `139`
- Route model:
- `/` homepage
- `/services` page index
- `/<spreadsheet-slug>` dynamic pSEO pages
